1. Non-Hosting Nature of Service

Our web application acts solely as an educational cinema metadata browser and search directory utilizing public REST APIs:

  • The Movie Database (TMDB) API for cast, genres, plot summaries, and official promotional trailer links.
  • TVMaze API for television broadcast metadata and schedules.
  • Public Domain Archives for open-access motion pictures released under Creative Commons or in the public domain.
